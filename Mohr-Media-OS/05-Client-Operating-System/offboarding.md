# Offboarding

Every client exits cleanly. Offboarding is a feature, not an afterthought. A strong offboarding produces referrals and case studies.

## When

- 30 days before contract end for scheduled completions
- Immediately on written notice for early termination
- After a 14 day retention sprint if the trigger is satisfaction based

## Checklist

- [ ] Schedule exit review call
- [ ] Transfer ownership of ad accounts, CRM pipelines, sequences, creative files, landing pages
- [ ] Deliver final runbook pack
- [ ] Deliver final case study draft if results support one
- [ ] Produce final insights note in the vault
- [ ] Request testimonial and case study permission in writing
- [ ] Ask for 3 referrals directly
- [ ] Remove Mohr Media access from shared tools
- [ ] Archive client vault folder into `10-Clients/archive/`

## Exit review agenda 45 minutes

1. Recap outcomes vs targets (10 min)
2. Walk the installed systems the client now owns (10 min)
3. Hand off runbooks and training (10 min)
4. Ask for testimonial, case study, referrals (10 min)
5. Close with next invitation (5 min)

## Rules

- No client exits without a vault archive
- No client exits without the testimonial and referral ask
- No hostile exits without orchestrator review
