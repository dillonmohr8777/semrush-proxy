# Workflow: Content Engine

## Objective

Install a weekly content engine that produces 2 long form pieces, 10 short form pieces, and 1 thread, all with distribution, and log the pipeline each piece produces.

## Strategy

Pillars first. Calendar second. Batch production third. Distribution before production. Attribution at day 14.

## Agents Used

- content-machine
- memory-engine
- ad-strategist (for amplification)

## Execution Plan

### Week 0: install

1. `content-machine` confirms pillars from `06-Content-Engine/content-pillars.md`
2. `content-machine` runs CP-01 if pillars need rebuild
3. `content-machine` runs CP-02 to build 30 day calendar

### Week 1 and ongoing: weekly batch

- Monday: topics and outlines
- Tuesday: long form drafts via CP-03
- Wednesday: humanize via CP-04, operator review
- Thursday: short form derivatives via CP-05
- Friday: distribution plan via CP-06 and schedule

### Day 14 post publish

1. `memory-engine` pulls metrics into vault notes
2. `ad-strategist` amplifies any piece above the winner threshold
3. `content-machine` logs content to pipeline rate
