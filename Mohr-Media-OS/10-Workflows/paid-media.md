# Workflow: Paid Media

## Objective

Install a paid media machine that pays back inside the target window with creative, landing pages, and CRO integrated.

## Strategy

Do not touch ads until the offer, landing path, and tracking are airtight. Then launch one channel at a time. Kill fast. Scale what works.

## Agents Used

- ad-strategist
- content-machine (for creative assets and scripts)
- memory-engine

## Execution Plan

### Sprint 1: foundation

1. `ad-strategist` runs prompt AP-01 for the 90 day media plan
2. `ad-strategist` runs prompt AP-04 on the current primary landing page
3. `ad-strategist` produces the full CRO audit report
4. Tracking QA: GA4, pixel, server side where applicable

### Sprint 2: creative and landing

1. `ad-strategist` runs prompt AP-02 for 10 creative angles
2. `content-machine` writes long form derivatives of winning angles
3. `ad-strategist` runs prompt AP-03 for landing page spec
4. `ad-strategist` builds landing page with `landing-page-generator` skill

### Sprint 3: launch

1. Follow `03-SOP-Library/ad-launch.md`
2. Daily standups for first 7 days
3. Day 7 report via prompt AP-05
4. Day 14 decision: kill, iterate, scale

### Sprint 4: compound

1. Feed winning creatives back to `content-machine` for organic reuse
2. `memory-engine` archives every creative and test
3. Add a second channel only after first channel is on target

## Assets Created

- 90 day media plan
- Full CRO audit
- 10 creative angles
- Landing page with tracking
- Campaign structure in each ad account
- Weekly paid media report template filled in

## Next Actions

1. Do not launch until CRO audit fixes ship
2. Do not scale until payback inside target window is proven
3. Cap initial test budget per channel to $5k until baseline is set
