# Workflows

Cross agent playbooks. Each workflow sequences multiple agents against one business objective and returns a report in the OS output contract.

## Files

- `client-acquisition.md`
- `content-engine.md`
- `paid-media.md`
- `sales.md`
- `delivery.md`
- `system-building.md`
- `memory.md`

## How to run a workflow

1. Name the objective in revenue terms
2. Open the matching workflow file
3. Run each agent in sequence
4. Capture every output in the vault
5. Return the report in the OS output contract
