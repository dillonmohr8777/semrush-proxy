## Execution Plan

### Sprint 1: Offer and ICP

1. `offer-architect` runs prompt OP-01 to produce the offer canvas
2. `offer-architect` runs prompt OP-04 to stress test positioning
3. `pipeline-builder` runs prompt PP-01 to produce the ICP scoring model

### Sprint 2: Outbound install

1. `pipeline-builder` runs prompt PP-02 to write cold email sequences
2. `pipeline-builder` runs prompt PP-03 for LinkedIn sequences
3. `content-machine` runs prompt CP-03 to produce three proof assets referenced in sequences
4. Operator loads lists, sends, monitors

### Sprint 3: Close motion install

1. `closer-engine` reads `07-Sales-System/discovery-call-script.md`
2. `closer-engine` runs prompt SP-01 for first three booked calls
3. `closer-engine` runs prompt SP-02 post call
4. `closer-engine` runs prompt OP-03 to produce custom proposals
5. Weekly pipeline report via prompt PP-05

### Sprint 4: Compound

1. `content-machine` repurposes weekly wins into social content
2. `ad-strategist` amplifies winning posts and writes first paid campaign if unit economics allow
3. `memory-engine` updates Insights MOC
