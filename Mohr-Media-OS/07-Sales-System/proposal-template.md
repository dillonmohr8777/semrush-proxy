# Proposal Template

```
# Proposal for {{client_name}}

Prepared by Mohr Media
Date: {{date}}
Version: 1.0

## 1. What you told me
- Current state in one paragraph, using their numbers.
- Pain in one sentence.
- Cost of inaction in one sentence with a dollar amount.
- Success picture at 90 days in one sentence.

## 2. What I heard you want installed
- System 1
- System 2
- System 3

## 3. The mechanism
Why Mohr Media installs systems instead of running retainers. Two short paragraphs.

## 4. Scope
### In scope
- Itemized list of installed systems and deliverables

### Out of scope
- Explicit list so there is no ambiguity

## 5. Timeline
| Week | Milestone | Owner |
|---|---|---|
| 1 | Kickoff and delivery spec | Mohr Media |
| 2-3 | Sprint 1 | Mohr Media |
| 4-5 | Sprint 2 | Mohr Media |
| 6 | Demo and retro | Joint |

## 6. Expected outcomes
| Metric | Baseline | Target at day 90 |
|---|---|---|
| Pipeline dollars per month | ... | ... |
| Qualified meetings per week | ... | ... |
| Close rate | ... | ... |
| Payback | ... | ... |

## 7. Proof
- Case study 1 link
- Case study 2 link
- Testimonial snippet

## 8. Price and terms
- Install fee: {{amount}}
- Operate fee: {{amount}} per month
- Payment terms: {{terms}}
- Cancellation: 30 day notice after operate month 3

## 9. What I need from you
- Access list
- Stakeholders at kickoff
- Decision by {{date}}

## 10. Guarantee
One clearly written guarantee that ties to a metric and a timeline.

## 11. Next step
Specific date and action to start.
```
