# Content Engine

Owned by `content-machine`. Every file here is designed so content compounds into pipeline rather than evaporating as impressions.

## Files

- `content-pillars.md`
- `production-workflow.md`
- `distribution-map.md`
- `hook-library.md`
- `post-templates.md`
- `calendar.md`

## Operating contract

Every piece produced must answer yes to all three:

1. Does it tie to a named pillar?
2. Is there a distribution plan before production starts?
3. Is there a tracked CTA that can be attributed to pipeline?

If any answer is no, the piece does not ship.
