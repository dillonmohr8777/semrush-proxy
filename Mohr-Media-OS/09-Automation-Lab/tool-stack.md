# Tool Stack

The opinionated defaults. Swap only when there is a written reason.

## Writing and thinking

- Claude Code CLI for system building
- Claude regular chat for ideation and quick execution
- Obsidian for the second brain

## Outbound

- Clay for enrichment and list building
- Smartlead for cold email sending
- Expandi or manual for LinkedIn outreach
- Lemlist or Instantly as fallback

## CRM

- Attio for operator led growth
- Hubspot if the client is already on it

## Sales calls

- Savvycal for scheduling
- Fathom for recording and transcription
- Notion or Obsidian for notes

## Content

- Notion or Obsidian for planning
- Google Docs for drafting when collaborating with clients
- Descript for video and podcast edits
- Canva for light visual work
- Figma for heavier design

## Ads

- Meta Ads Manager
- Google Ads
- LinkedIn Campaign Manager
- Triple Whale or Northbeam for attribution at scale

## Analytics

- GA4 as the baseline
- Plausible for privacy friendly tracking
- Segment or Rudderstack when client is event heavy

## Automation runtime

- Make for most glue automations
- n8n when self hosted is required
- Zapier only when the team already knows it

## Version control

- GitHub for all runbooks, specs, and prompts

## Password and secrets

- 1Password for credentials
- Doppler or Vault for infra secrets when needed

## Rules

- No tool joins the stack without a named owner
- No tool stays without a documented runbook
- Every duplicate tool gets killed inside 30 days
