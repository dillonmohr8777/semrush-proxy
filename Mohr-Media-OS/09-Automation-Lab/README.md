# Automation Lab

The place where manual work turns into machines. Owned by execution-engine with orchestrator oversight.

## Files

- `automation-roadmap.md`
- `integrations.md`
- `workflow-specs.md`
- `tool-stack.md`

## Principle

Automate anything repeated 5 times or more. Leave anything that is genuinely one off. Do not automate judgement.

## Funnel for every candidate

1. Name the manual task
2. Count how many times per week it runs
3. Estimate operator minutes per run
4. Estimate automation cost (build + run)
5. Calculate weeks to payback
6. If payback under 8 weeks, ship
7. If payback 8 to 16 weeks, queue
8. If payback over 16 weeks, reject or redesign
