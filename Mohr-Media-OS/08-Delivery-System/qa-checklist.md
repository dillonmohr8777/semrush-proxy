# QA Checklist

No client facing asset ships without passing this gate.

## Universal checks

- [ ] Does this asset map to a named revenue outcome?
- [ ] Is the owner assigned and named?
- [ ] Is the runbook updated?
- [ ] Is the asset stored in the client folder under version control?
- [ ] Is there a vault entry scheduled for ingest?

## Copy checks

- [ ] No em dashes
- [ ] No AI tells (delve, embark, harness, in today's world, etc.)
- [ ] Exactly one primary CTA
- [ ] Proof visible early
- [ ] Claims sourced

## Technical checks

- [ ] Tracking installed and firing
- [ ] Mobile parity verified
- [ ] Forms capturing required fields only
- [ ] Redirects working
- [ ] Load time under 3 seconds

## Brand checks

- [ ] Matches client brand voice reference
- [ ] Uses approved visual system
- [ ] Approved by named stakeholder in writing

## Go live checks

- [ ] Launch window approved
- [ ] Rollback plan documented
- [ ] Success and kill criteria named

## Rules

- A single failed check blocks ship
- Any override requires orchestrator sign off in writing
- Every override is logged in the vault
