# Maps of Content

Every MOC lives in `99-Meta/MOCs/`. A MOC is not a note dump. A MOC is a curated navigation layer with the best examples, the playbooks, and the open questions.

## MOC list

1. `MOC-Clients.md`
2. `MOC-Offers.md`
3. `MOC-ICPs.md`
4. `MOC-Channels.md`
5. `MOC-Experiments.md`

7. `MOC-Playbooks.md`
8. `MOC-People.md`
9. `MOC-Competitors.md`
10. `MOC-Tools.md`

## MOC template

```
---
type: moc
updated: {{date}}
---

# <Topic> MOC

## Purpose
One sentence.

## Active entries
- [[entry1]]
- [[entry2]]

## Playbooks
- [[playbook1]]

## Top insights
- [[insight1]]
- [[insight2]]

## Open questions
- Question 1
- Question 2

## Archived
- [[archived-entry]]
```

## Update cadence

- `MOC-Clients` updates when a client joins, changes stage, or churns
- `MOC-Offers` updates every offer version change
- `MOC-Experiments` updates at experiment end date
- `MOC-Insights` updates weekly during the weekly review
- All other MOCs update at least once per quarter
