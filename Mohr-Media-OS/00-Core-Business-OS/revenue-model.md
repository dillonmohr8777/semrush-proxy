# Revenue Model

## Product shape

Mohr Media sells installed systems in three tiers. Every tier produces a durable asset the client owns.

## Tier 1: Offer and Pipeline Install

Scope:

- ICP definition and qualification scoring
- Offer design, pricing, and proof architecture
- Cold outbound infrastructure and sequences
- Inbound content pillar and distribution plan
- Sales enablement kit and call frameworks

Pricing shape: fixed project fee plus a 60 day operate period.

Target outcome: first 10 qualified conversations booked inside 30 days, first closed deal inside 60 days.

## Tier 2: Paid Media and CRO Install

Scope:

- Ad account structure and creative system
- Landing page and conversion path install
- Full CRO audit across page, form, signup, onboarding, popup, paywall
- Reporting dashboard and attribution model

Pricing shape: fixed install plus performance based operate retainer.

Target outcome: positive payback inside 90 days, continuous ROAS optimization.

## Tier 3: Full Revenue Operating System

Scope:

- Everything in Tier 1 and Tier 2
- Content engine install and ghostwritten distribution
- Sales system install with pipeline management
- Weekly operator reporting
- Obsidian second brain and memory engine
- Automation lab roadmap and first three automations shipped

Pricing shape: quarterly install plus monthly operate.

Target outcome: client operates a predictable revenue machine by month 4 and owns every component.

## Unit economics we run

| Lever | Why it matters |
|---|---|
| Average contract value | Sets ceiling on acquisition cost |
| Gross margin | Determines reinvestment capacity |
| Delivery hours per client | Caps concurrent clients |
| Renewal or retention value | Converts one time revenue into annuity |

## What we never sell

- Pure hourly consulting
- Retainers with no defined output
- Deliverables without a pipeline or revenue target
- Work priced by seniority instead of outcome
