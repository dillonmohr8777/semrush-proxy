# Trailer Concepts

> Book trailer ideas for social media and website.

## Concept 1: The System
- 30-60 seconds
- Slow, atmospheric footage of institutional spaces
- Text overlays: key quotes from the book
- Sound: Low, building tension
- Ends with: Title + tagline + "Available [date]"

## Concept 2: The Question
- 15-30 seconds (social-optimized)
- Text-only on dark background, building one question at a time
- "What if the incompetence... isn't incompetence?"
- Ends with: Title + cover

## Concept 3: Character-Driven
- 45-60 seconds
- Brief atmospheric vignettes representing each character
- Voiceover: Key lines from each character
- Ends with: "The system isn't broken. It was built this way."

## Production Notes
- Can be created with stock footage + motion graphics
- No actors needed - atmospheric and text-driven
- Must match brand aesthetic (dark, institutional, textured)
- Vertical versions needed for social
