# Image Prompts

> AI image generation prompts and visual concept briefs for marketing assets.

## Blog Featured Images
| Blog Topic | Visual Concept | Style Notes |
|-----------|---------------|-------------|
| Political thriller themes | Dark institutional hallway, marble, shadows | Moody, desaturated |
| Surveillance state fiction | Array of screens, security cameras, data streams | Cold, clinical |
| Meritocracy in fiction | Tilted scales, broken ladder, glass ceiling | Symbolic, abstract |
| Character spotlights | Character-appropriate atmosphere, no faces | Atmospheric, suggestive |

## Social Media Graphics
- Quote cards: Dark background, clean typography, brand colors
- Character spotlights: Atmospheric silhouettes or abstract representations
- Theme posts: Symbolic imagery matching the theme

## Style Guide for Generated Images
- Always dark and moody
- Prefer abstract/symbolic over literal
- No identifiable faces (don't lock in character appearances)
- Consistent color palette across all assets
- Should feel sophisticated, not pulpy
