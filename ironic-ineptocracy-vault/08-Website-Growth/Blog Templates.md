# Blog Templates

> Standard structures for different blog post types. Keeps quality consistent.

## Type 1: List Post ("Best X for Y")
```
# [Number] [Category] [Qualifier]
## Introduction (100-150 words)
- Hook the reader with the pain point or curiosity
- Establish why this list matters
- Brief mention of The Ironic Ineptocracy's place in the list

## [Item 1]
- Description, why it belongs, what makes it notable
## [Item 2]
...

## Conclusion
- Recap the theme
- CTA to the book
```

## Type 2: Theme Essay
```
# [Theme]: [Provocative angle]
## The Setup (150 words)
- Establish the theme and why it matters now
## The Exploration (500-800 words)
- Deep dive into the theme
- Reference real-world and fictional examples
- Weave in the novel's perspective naturally
## The Connection (100 words)
- How The Ironic Ineptocracy explores this
## CTA
```

## Type 3: Character Spotlight
```
# Meet [Character]: [One-line hook]
## Who Is [Character]?
- Role, background, what drives them
## What Makes Them Compelling
- Internal conflict, unique perspective
## A Taste (Excerpt or Quote)
## Read Their Full Story
- CTA to buy/read
```

## Type 4: Behind-the-Scenes
```
# [Personal/Process angle]
## The Story Behind...
- Personal, authentic, not promotional
## What I Learned
## What It Means for the Book
## CTA (soft)
```

## Type 5: Comparison / "Books Like..."
```
# Books Like [Comp Title]: [Number] Reads for Fans of [Quality]
## Why [Comp Title] Resonates
## If You Loved [Quality], Try These:
### [Book 1] - including The Ironic Ineptocracy
### [Book 2]
...
## Find Your Next Read
- CTA
```
