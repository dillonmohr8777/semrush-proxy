# Conversion Paths

> How visitors move from discovery to action.

## Path 1: SEO Blog → Book Page → Buy/Signup
- Entry: Organic search lands on blog post
- Action: Reader clicks internal link to book page
- Conversion: Preorder, buy, or email signup
- Optimize: Blog CTAs, book page conversion elements

## Path 2: Theme Page → Character Page → Excerpt → Signup
- Entry: Theme-based search lands on theme page
- Action: Curiosity about characters, clicks to character page
- Next: Clicks "read the first chapter"
- Conversion: Email signup for chapter PDF
- Optimize: Theme-to-character linking, excerpt page form

## Path 3: Direct Search → Homepage → Buy
- Entry: Brand search or word-of-mouth
- Action: Lands on homepage
- Conversion: Direct buy/preorder
- Optimize: Homepage hero, CTA placement, buy links

## Path 4: Social → Landing Page → Signup
- Entry: Social post links to specific landing page
- Conversion: Email signup or book page visit
- Optimize: Social content quality, landing page match

## Path 5: Outreach → Press Page → Book Page → Buy
- Entry: Reviewer/podcaster visits press page
- Action: Downloads press kit, reads about book
- Conversion: Reviews book or features it
- Optimize: Press page completeness, easy asset downloads
