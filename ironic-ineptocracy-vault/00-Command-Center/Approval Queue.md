## Approval Template

When adding items to this queue, include:

```
### [Asset Title]
- **Type:** Blog / Landing Page / Homepage Edit / Outreach / Social / Other
- **Priority:** High / Medium / Low
- **Date Staged:** YYYY-MM-DD
- **Purpose:** Why this matters
- **Expected Upside:** What it should accomplish
- **Risk:** What could go wrong (if any)
- **WordPress Draft Link:** (if applicable)
- **Decision Needed:** Approve to publish / Revise / Kill
```
