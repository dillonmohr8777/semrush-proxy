# Brand Guardrails

> Non-negotiable rules for all public-facing content about The Ironic Ineptocracy.

## Tone
- Intelligent, sharp, deliberate
- Never condescending or preachy
- Let the themes speak - don't explain them like a textbook
- Dark when appropriate, never gratuitously edgy
- Confident without being arrogant

## Voice Rules
- Write like the book reads - direct, layered, purposeful
- Avoid generic book marketing language ("page-turner!", "thrilling ride!", "a must-read!")
- Avoid AI-sounding copy (no "delve", "tapestry", "in a world where...")
- Avoid oversimplifying the themes
- Never reduce complex characters to stereotypes
- Use the novel's own language and energy when possible

## Canon Rules
- All character descriptions must match `02-Characters/` profiles
- All plot references must match `03-Plot-and-World/` notes
- All theme framing must align with `01-Story-Core/Core Themes.md`
- Never reveal plot spoilers beyond what's approved in `03-Plot-and-World/Public Spoiler Rules.md`
- Never fabricate quotes, reviews, or endorsements

## Messaging Boundaries
- The book explores systemic power, race, meritocracy, and surveillance - treat these with the weight they deserve
- Never use the themes as clickbait
- Never take explicit partisan political positions on behalf of the book - the book asks questions, it doesn't campaign
- Never make claims about the book that the text doesn't support
- Let readers draw their own conclusions - marketing should intrigue, not prescribe

## Visual Rules
- Reference `04-Brand/Visual Identity.md` for approved colors, fonts, and imagery direction
- No stock-photo-looking imagery
- Aesthetic should match the novel's atmosphere: institutional, shadowy, textured

## SEO Rules
- Target keywords must be relevant to the book's actual themes and genre
- Never keyword-stuff or publish thin content for rankings alone
- Every page must provide genuine value to the reader who lands on it
- Prefer long-form authority content over high-volume filler
