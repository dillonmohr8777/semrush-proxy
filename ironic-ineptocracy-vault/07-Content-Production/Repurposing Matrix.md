# Repurposing Matrix

> Every approved blog post becomes a week of multi-channel content.

## The Formula

One approved blog post generates:

| Output | Platform | Format | Timeline |
|--------|----------|--------|----------|
| 3 posts | X / Twitter | Quote + insight + question | Same week |
| 2 captions | Instagram | Visual quote + narrative caption | Same week |
| 1 post | LinkedIn | Professional angle on the theme | Same week |
| 1 script | TikTok / Reel | 30-60s talking point or hook | Same week |
| 3 concepts | Quote graphics | Key lines with brand styling | Same week |
| 1 angle | Email / Newsletter | Personalized take for subscribers | Next send |
| 1 thread | Reddit | Discussion prompt for relevant sub | When natural |

## Repurposing Workflow
1. Blog post gets approved and published
2. Claude generates all derivative content
3. Derivative content goes into `Drafts/` with platform labels
4. Social content queued for the week
5. Email angle queued for next newsletter
6. Reddit angle held for organic timing

## Rules
- Every derivative must link back to the original post or the book page
- Social content must stand alone (don't just tease the blog)
- Each platform gets native formatting (no copy-paste across platforms)
- Quote graphics need visual concept notes (Claude can't design, but can brief)
