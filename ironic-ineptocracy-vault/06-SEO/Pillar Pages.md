# Pillar Pages

> High-authority pages that anchor keyword clusters. Each pillar links to supporting blog posts.

## Pillar 1: The Book
- **URL:** / (homepage) or /the-book
- **Target:** branded searches, book title, summary
- **Structure:** Book description, themes overview, character preview, excerpt CTA, buy/preorder
- **Internal links to:** Character pages, theme pages, excerpt page

## Pillar 2: Characters Hub
- **URL:** /characters
- **Target:** character-related searches
- **Structure:** Overview of main characters with teasers, links to individual character pages
- **Internal links to:** Individual character pages, relationships, book page

## Pillar 3: Themes Hub
- **URL:** /themes
- **Target:** theme-based discovery searches
- **Structure:** Overview of core themes, why they matter, links to deep-dive pages
- **Internal links to:** Individual theme pages, blog posts about each theme

## Pillar 4: Blog Hub
- **URL:** /blog
- **Target:** informational queries, genre discovery
- **Structure:** Categorized by cluster (political fiction, themes, behind-the-scenes)
- **Internal links to:** All blog posts, theme pages, book page

## Pillar 5: About the Author
- **URL:** /about
- **Target:** author name searches, credibility
- **Structure:** Author bio, why this book, writing philosophy, social links
- **Internal links to:** Book page, blog, press page

## Internal Linking Rules
- Every blog post links to at least one pillar page
- Every pillar page links to its supporting content
- Character pages link to theme pages when relevant
- All pages link to the primary CTA (buy/preorder/signup)
