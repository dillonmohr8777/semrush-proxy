# On-Page SEO Rules

> Standards for every page on ironicineptocracy.com.

## Title Tags
- Max 60 characters
- Include primary keyword
- Include brand when possible: "... | The Ironic Ineptocracy"
- Format: [Primary Keyword] - [Hook or Qualifier] | The Ironic Ineptocracy

## Meta Descriptions
- Max 155 characters
- Include primary keyword naturally
- Include a hook or CTA
- Never duplicate across pages

## Headings
- One H1 per page (includes primary keyword)
- H2s for major sections (include secondary keywords)
- H3s for subsections
- Never skip heading levels

## Content Rules
- Minimum 800 words for blog posts
- Minimum 500 words for landing pages
- Include primary keyword in first 100 words
- Use related keywords naturally throughout
- Include at least 2 internal links per page
- Include at least 1 CTA per page

## URL Structure
- Lowercase, hyphenated
- Short and descriptive
- Include primary keyword when natural
- Example: /surveillance-state-fiction NOT /blog/post-47

## Images
- Descriptive alt text with keyword when natural
- Compressed file sizes
- Descriptive filenames (not IMG_0042.jpg)

## Schema Markup Opportunities
- Book schema on main book page
- Author schema on about page
- Article schema on blog posts
- FAQ schema on FAQ page
- Review schema when reviews exist
