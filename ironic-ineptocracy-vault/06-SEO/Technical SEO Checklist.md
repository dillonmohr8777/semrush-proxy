# Technical SEO Checklist

> Site health items Claude checks periodically.

## Core Vitals
- [ ] Page load time under 3 seconds
- [ ] Mobile responsive on all pages
- [ ] No layout shift issues
- [ ] Core Web Vitals passing in Search Console

## Indexing
- [ ] XML sitemap submitted and current
- [ ] robots.txt not blocking important pages
- [ ] All key pages indexed in Google
- [ ] No accidental noindex tags
- [ ] Canonical tags correct on all pages

## Technical
- [ ] SSL certificate active and valid
- [ ] No mixed content warnings
- [ ] 404 page exists and is useful
- [ ] No broken internal links
- [ ] No redirect chains or loops
- [ ] Structured data validates without errors

## Content
- [ ] No duplicate title tags
- [ ] No duplicate meta descriptions
- [ ] No thin pages (under 300 words with no other value)
- [ ] No orphan pages (no internal links pointing to them)
- [ ] No cannibalization (two pages targeting same keyword)
