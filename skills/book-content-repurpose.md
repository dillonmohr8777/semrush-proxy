# Skill: Book Content Repurpose

## When to use
After a blog post is approved and published for The Ironic Ineptocracy. Turns one piece of content into a week of multi-channel assets.

## Steps

1. **Read the Approved Post**
   - Get the published blog post content
   - Identify key themes, quotes, and arguments

2. **Read Repurposing Rules**
   - Read `ironic-ineptocracy-vault/07-Content-Production/Repurposing Matrix.md`
   - Read `ironic-ineptocracy-vault/04-Brand/Voice and Tone.md`

3. **Generate X / Twitter Content (3 posts)**
   - Post 1: Key insight or provocative question from the article
   - Post 2: Quote or statistic from the article
   - Post 3: "Thread hook" version - summarize in 3-5 tweets
   - Each must stand alone (not just tease the blog)
   - Include link to original post

4. **Generate Instagram Content (2 posts)**
   - Caption 1: Narrative hook + key takeaway + CTA
   - Caption 2: Quote from the article formatted for visual
   - Note visual concept for each (for image prompt)

5. **Generate LinkedIn Post (1 post)**
   - Professional angle on the same theme
   - Longer format (150-300 words)
   - Link to blog post

6. **Generate TikTok/Reel Script (1 script)**
   - 30-60 second talking point
   - Hook in first 3 seconds
   - One clear idea

7. **Generate Quote Graphic Concepts (3)**
   - Select best lines from the post
   - Note visual treatment per `ironic-ineptocracy-vault/13-Assets/Image Prompts.md`

8. **Generate Email Angle (1)**
   - Personalized take for newsletter subscribers
   - Link to full post
   - Unique opening (not the same as the blog intro)

9. **Generate Reddit Angle (1)**
   - Discussion prompt format for relevant subreddit
   - Must add value independent of the book
   - Follow `ironic-ineptocracy-vault/09-Social-and-Launch/Reddit Strategy.md` rules

10. **Save All Content**
    - Save to `ironic-ineptocracy-vault/07-Content-Production/Drafts/` with platform labels
    - Update Editorial Calendar
    - Update Dashboard action log

11. **Notify**
    - Send Slack summary: "[Blog title] repurposed into [X] assets across [Y] platforms"
