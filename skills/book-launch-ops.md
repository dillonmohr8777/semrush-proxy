# Skill: Book Launch Ops

## When to use
When asked to check launch readiness, update launch status, or manage launch campaign tasks for The Ironic Ineptocracy.

## Steps

1. **Read Context**
   - Read `ironic-ineptocracy-vault/00-Command-Center/Dashboard.md`
   - Read `ironic-ineptocracy-vault/09-Social-and-Launch/Launch Countdown.md`

2. **Calculate Days to Launch**
   - Check launch date
   - Determine which phase we're in (90/60/30/launch week/post-launch)

3. **Checklist Review**
   - Go through the checklist for the current phase
   - Mark completed items
   - Flag overdue items
   - Identify blocked items

4. **Content Pipeline Status**
   - Check `ironic-ineptocracy-vault/07-Content-Production/Editorial Calendar.md`
   - Are we on pace for planned content?
   - How many blog posts are published?
   - How many are in the approval queue?

5. **Outreach Status**
   - Check `ironic-ineptocracy-vault/10-Outreach/Podcast Targets.md` - any responses?
   - Check `ironic-ineptocracy-vault/10-Outreach/Book Reviewers.md` - ARCs sent?
   - Check `ironic-ineptocracy-vault/10-Outreach/Substack Targets.md` - any features?

6. **Website Readiness**
   - Is the site live and optimized?
   - Are all key pages published?
   - Is email capture working?
   - Is the buy/preorder flow ready?

7. **Social Readiness**
   - Are social profiles set up and active?
   - Is launch content drafted?
   - Is the countdown sequence ready?

8. **Report**
   - Update Launch Countdown checklist
   - Update Dashboard with launch status
   - Send Slack summary: "Launch readiness: [X] days out. [Y] items complete, [Z] items pending."
   - Flag any blockers

9. **Log**
   - Update Dashboard action log
