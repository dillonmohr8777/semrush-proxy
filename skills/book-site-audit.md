# Skill: Book Site Audit

## When to use
When asked to audit the ironicineptocracy.com website for content quality, conversion optimization, and completeness.

## Steps

1. **Read Context**
   - Read `ironic-ineptocracy-vault/00-Command-Center/Dashboard.md`
   - Read `ironic-ineptocracy-vault/08-Website-Growth/Homepage Optimization.md`

2. **Page Inventory**
   - `list_pages` on ironicineptocracy.com
   - For each page, note: title, status, URL, last updated
   - Compare against needed pages in `ironic-ineptocracy-vault/08-Website-Growth/Landing Pages.md`

3. **Content Quality Review**
   - `get_page` for each key page
   - Check: word count, heading structure, CTA presence, internal links
   - Check for thin content (under 300 words)
   - Check for missing metadata

4. **Conversion Review**
   - Is there a clear CTA above the fold on the homepage?
   - Is email capture present and visible?
   - Do character/theme pages link to buy/signup?
   - Is the purchase/preorder flow clear?
   - Reference `ironic-ineptocracy-vault/08-Website-Growth/Conversion Paths.md`

5. **Missing Pages Check**
   - Compare existing pages against the full plan:
   - Character pages?
   - Theme pages?
   - FAQ page?
   - Press/media page?
   - Discussion guide?
   - First chapter excerpt?

6. **Report**
   - Update `ironic-ineptocracy-vault/04-Brand/Website Notes.md` with findings
   - Update `ironic-ineptocracy-vault/08-Website-Growth/CRO Notes.md`
   - Add opportunities to Dashboard
   - Send Slack report

7. **Log**
   - Update Dashboard action log
