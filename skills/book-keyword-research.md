# Skill: Book Keyword Research

## When to use
When asked to do keyword research for the book, refresh the keyword universe, or find new content opportunities.

## Steps

1. **Read Context**
   - Read `ironic-ineptocracy-vault/06-SEO/Keyword Universe.md`
   - Read `ironic-ineptocracy-vault/06-SEO/Keyword Clusters.md`

2. **Seed Keyword Expansion**
   - `keyword_ideas` for each seed keyword in the universe
   - `keyword_questions` for content and FAQ opportunities
   - `keyword_overview` for any promising new terms

3. **Competitor Keyword Mining**
   - Identify 3-5 comp title websites
   - `domain_organic_keywords` for each
   - `keyword_gap` between ironicineptocracy.com and competitors
   - Note keywords where competitors rank but we don't

4. **Evaluate Opportunities**
   - Filter by: relevance to book themes, search volume, competition level
   - Prioritize: high relevance + low competition = quick wins
   - Tag each keyword with search intent (informational, navigational, transactional)

5. **Update Vault**
   - Update `ironic-ineptocracy-vault/06-SEO/Keyword Universe.md` with new findings
   - Update `ironic-ineptocracy-vault/06-SEO/Keyword Clusters.md` if new clusters emerge
   - Add content ideas to `ironic-ineptocracy-vault/07-Content-Production/Blog Ideas.md`
   - Update `ironic-ineptocracy-vault/05-Audience/Search Intent Map.md`

6. **Recommendations**
   - Top 5 new keywords to target (with suggested content type)
   - New landing page opportunities
   - Blog topics to add to editorial calendar
   - Update Dashboard with opportunities found

7. **Log**
   - Update Dashboard action log
   - Note date of research refresh in Keyword Universe
